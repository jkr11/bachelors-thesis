This chapter introduces the theory of \emph{anyons} not by their algebra (cf.
\cref{sect:Categories}) but by their physical instantion.

In the contemporary literature, anyons are introduced as \emph{defects} in a $2$
dimensional space (manifold? compact?) with \emph{exotic exchange statistics} on
its wave functions. These exchange statistics differ from bosons or fermions in
that we allow particles to pick up an arbitrary complex phase $e^{i\theta}$ on
exchanges in the abelian case, and a unitary transformation in the non-abelian
case. Here we introduce as one would have found by doing elementary analysis on
the \emph{parameter space} of point-like particles. We argue why these systems
are important and why these are called \emph{topological}. Ending this chapter
we sketch the motivations for translating this approach into an algebraic
description using \emph{categories} and their corresponding string
calculi\todo{Is this string calc or only diagrams?}.

\section{Configuration Spaces \& The Braid Group}
\label{sect:anyons1:configurations_spaces_and_the_braid_group}

The original article by \textcite{leinaasTheoryIdenticalParticles1977a}
identifies a generalized theory of \emph{identical} particles that are
point-like. Denote the ambient space that such a particle inhabits by $\Sigma$
and then the space of $n$ identical particles possible coordinates  by $\Sigma^n
\coloneqq \bigtimes^n \Sigma$. Since the particles are assumed to be
indistinguishable, any permutation, so an action of $\Sym_n$ (cf.
\cref{app:gen:groups}) necessarily leads to the same physical state, so we
denote the full space of our system by the quotient
\[
    \Sigma^n / \Sym_n.
\] 
However we also want no two particles occupying the same space\footnote{If this
were the case, then the resulting exchange statistics would be bosonic
\cite[Footnote~12]{wuGeneralTheoryQuantum1984}.}, so the diagonal of overlapping
points $\Delta = \{x \in \Sigma^n \mid x_i = x_j \text{ for some } i \neq
j\}$\todo{rephrase!} needs to be excluded as well
\cite{wuGeneralTheoryQuantum1984}. This leads to the expression
%\[
%    \uConf_n(\Sigma) = (\Sigma^n - \Delta) / S_n
%\]  
\begin{equation}\label{anyon:conf_space_full}
  \uConf_n(\Sigma) = \left\{(x_1, \cdots, x_n) \in \Sigma^{\times^n} \mid \displaystyle\forall_{i = j} x_i \neq x_j \right\} / \Sym_n 
\end{equation}
which is defined to be the \emph{configuration space} of $n$ unordered
particles. However as we will see, anyons come in different "types", and we
consider only particles of the same type to be identical. This entails that we
also need a concept o a configuration space that is not ordered. We follow
\cite{satiDifferentialCohomotopyImplies2022}\todo{original publications.} with
the following definition:
\begin{definition}
    The \emph{\green{ordered Configuration Space}} of $n$ particles of possibly
    differnt types (or labeled particles with the same type) on a surface of
    dimension $D$ is
    \[
        \oConf n (\Sigma) := (\Sigma)^n - \Delta_{\Sigma}^n
    \] 
    and the \emph{\green{unordered Configuration Space}} of $n$ unlabeled
    identical particles is defined as 
    \[
        \uConf_n (\Sigma) := \oConf n (\Sigma) / \Sym_n.
    \]
\end{definition}

Note that while \cite{leinaasTheoryIdenticalParticles1977a} conjectured
computations for strange exchange statistics in both $2$ and $3$ dimensions, the
concept of an anyon as a $1$ dimensional representation of the braid group

Now we want to classify all the possible motions particles can take in this
space. Here we let these motions account for time evolutions. The \emph{motion
group} of the configuration space is given by the spaces \emph{homotopy classes}
(cf. \Cref{app_gen:homotopy}), which are given by the fundamental
group(oid)\footnote{One should rather use the groupoid here, since in a real
scenario these particles likely will not hit the same return point. But the only
part that i know of that defines it this way is the source
\cite{neoriIdenticalParticlesQuantum2016}.} of the space. Informally, this group
collects all the loops at some configuration $x_0$ (a point in the configuration
space) up to homotopy. We want to differentiate two cases here: If $D = 2$ it is
known these spaces correspond to the \emph{(pure) braid groups} on $n$ strands
denoted
\[
    \pi_1(\uConf_n (\Sigma)) = \Br_n(\Sigma) \quad \text{ and } \quad \pi_1(\oConf{n} (\Sigma)) = \PBr_n(\Sigma).
\]
If we choose $\Sigma$ as $\R^2$ we can give an presentation in terms of
generators:
\begin{definition}[Braid Group, cf. {\cite{artinTheorieZoepfe1925} \cite[~Def.
  II]{wilsonGeometryTopologyBraid}}] The braid group (on the plane $\R^2$) is
  defined in terms of its generators:
\begin{equation}
  \label{sym:eq:ArtinBraidPresentation}
  \mathrm{Br}_n(\R^2)
  \;\simeq\;
  \left\langle\,
    \sigma_1, \cdots, \sigma_{n-1}
    \;\middle|\;
    \begin{gathered}
      \underset{
        i + 1 < j
      }{\forall}
      \big(
        \sigma_i \sigma_j
        =
        \sigma_j \sigma_i
      \big)
      \,,
      \\
      \underset{
        1 \leq i < n - 1
      }{\forall}
      \underset{
        \mathclap{
          \scalebox{.7}{\textcolor{gray}{\text{Yang--Baxter relation}}}
        }
      }{
        \big(
          \sigma_i \, \sigma_{i + 1} \, \sigma_i
          \,=\,
          \sigma_{i + 1} \, \sigma_i \, \sigma_{i + 1}
        \big)
      }
    \end{gathered}
    \,\right\rangle
  \,,
\end{equation}
\end{definition}

However now if $D >= 3$ we know that both of these coincide with the symmetric
group $\Sym_n$ instead. In fact there is an exact sequence
\[
    1 
    \longrightarrow 
    \mathrm{PBr}_n(\Sigma) 
    \lhook\joinrel\longrightarrow
    \mathrm{Br}_n(\Sigma)
    \longrightarrow 
    \Sym_n 
    \longrightarrow 
    1
\]
and this is quite best understood forgetting what an anyon is, the configuration
space intrinsically has no knowledge of what it is either, it only knows its
points. In the case of the ordered configuration space these points are each
endowed with a label, and these may yet correspond to identical particles in the
physical layer. So the pure braid group requires a motion to end up at its exact
starting configuration, so it has no permutation of labels. The braid groups
generator $\sigma_i$ hover can be directly mapped to the symmetric groups $s_i$,
thus we say there is a group homomorphism $\Br_n \to \Sym_n$. Since the pure
braid group does not induce \emph{any} permutation but the trivial one, it must
be in the kernel of this homomorphism.




Compare this to the presentation of the symmetric group (cf.
\cref{app:gen:groups}) to see that $\Sym_n$ is a \emph{subgroup} of
$\Br_n(\R^2)$.

\begin{remark}
  This is not to assert that anyons (rather anyonic excitations) do not exist
  $3$ or more dimensions, this simply states that there are no \emph{point-like
  defects} in $3$ or more dimensions that behave as anyons. Sheet and

\end{remark}

To reiterate, the configuration space here takes the role of a \emph{classical}
parameter space. Any quantum process we give on this state should ideally
\emph{parameterized} by the configuration space itself. To make this a formal definition, we associate a Hilbert space to each point in the configuration space by using a \emph{Hilbert bundle} (cf. \cref{app_gen:homotopy}).
\[
  \mathcal{H} \overset{\pi}{\longrightarrow} \oConf{n}(\Sigma),
\]
i.e. to each point $x \in \oConf{n}(\Sigma)$ there is an associated Hilbert
space $\mathcal{H}_{x}$ called the \emph{fiber} of $x$. Furthermore, a path
through the configuration space $[\gamma] : x_0 \to x_1 \in \oConf{n}(\Sigma)$
is lifted to some unitary representation
\[
  \rho([\gamma]) \in U(\mathcal{H}_{x_0} \to \mathcal{H}_{x_1})
\]
by \emph{parallel transport}. Since we care about the topology of the system, we
would like our paths to be \emph{homotopy protected}. So any topological
deformation (so not cuttings or crossings) can be resolved back to itself.
However if we follow two paths in the configuration space that are \emph{not}
homotopic, we want \emph{distinctly robust transformations} on the fibers of the
space. We can illustrate this as follows (adapted after

Now we need to introduce anther assumption, that anyons are spatially localized
phenomena. This means that in every $n$-anyon system we can look at a $k$-anyon
subsystem (such that they are adjacent) and apply evolutions only within this
subsystem. Then the other anyons outside of the system are not affected by this.
Note that this correlates with the inclusion $\Br_k \hookrightarrow \Br_n$ since
while we could always take the restriction
\[
  \rho_{
    |\Br_k
  } : \Br_k \to \U{\mathcal{H}_n}.
\]
we are now allowed, by the postulate of locality that we can also take this
restriction with a proper subsystem $H_k \subseteq H_n$ as 
\[
  \rho_{
    |\Br_k
  } : \Br_k \to \U{\mathcal{H}_k}.
\]

\[
